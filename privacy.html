개인정보처리방침

노미 경제 방송(이하 "이 도구")은 채널 운영자가 자신의 PC에서 직접 실행하는 개인용 도구입니다.

사용하는 정보

  • Google 계정으로 연결할 때 허용한 범위 안에서 운영자 본인의 YouTube 채널 정보(채널 ID, 채널 이름)를 확인합니다.
  • 운영자가 고른 영상을 운영자 본인의 채널에 업로드하고, 업로드 상태와 썸네일을 확인·등록합니다.
  • 라이브 방송 진행에 필요한 방송 정보를 만들고 관리합니다.

보관과 공유

  • Google 연결 정보(인증 토큰)는 운영자의 PC에만 암호화해 저장하며, 외부 서버로 보내지 않습니다.
  • Google 사용자 데이터를 제3자에게 판매하거나 공유하지 않으며, 광고에 사용하지 않습니다.
  • 이 도구가 Google API로 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

연결 해제

운영자는 언제든지 이 도구의 게시 탭에서 연결을 해제하거나, Google 계정 설정(https://myaccount.google.com/permissions)에서 접근 권한을 철회할 수 있습니다.

문의

문의는 Google 동의 화면에 표시된 지원 이메일로 해 주세요.
